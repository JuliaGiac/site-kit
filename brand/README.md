# JuliaGiac visual identity

![JuliaGiac mark](assets/juliagiac-mark.png)

The mark is a **G** whose crossbar is the overline of a **square root sign**,
with the **three Julia dots** above its opening: Giac, a computer algebra
system, in Julia.

Every file in `assets/` is generated by [`make_brand.jl`](make_brand.jl) with
[Luxor.jl](https://github.com/JuliaGraphics/Luxor.jl). Do not edit the assets
by hand: change the constants at the top of the script and regenerate.

```sh
just brand
# or
julia --project=brand -e 'using Pkg; Pkg.instantiate()'
julia --project=brand brand/make_brand.jl
```

## Assets

| File | Use |
|------|-----|
| `juliagiac-mark.svg` / `.png` | The mark on light backgrounds (transparent) |
| `juliagiac-mark-light.svg` / `.png` | The mark on dark backgrounds (transparent) |
| `juliagiac-avatar.svg` / `.png` | Organisation and repository avatar, 1024×1024 |
| `favicon.svg` / `.png` | Web site favicon, 64×64, rounded corners |
| `apple-touch-icon.png` | iOS home-screen icon, 180×180 |
| `social-preview.png` | GitHub social preview of the repositories, 1280×640 |

## Palette

| Name | Value | Role |
|------|-------|------|
| Ink | `#222326` | The mark on light backgrounds; dark backgrounds |
| Paper | `#F5F5F7` | The mark on dark backgrounds |
| Muted | `#A0A4A8` | Secondary text on dark backgrounds |
| Julia red | `#CB3C33` | First dot |
| Julia green | `#389826` | Second dot |
| Julia purple | `#9558B2` | Third dot |

The three dot colours are those of the Julia logo. Do not recolour the dots
or reorder them.

## Text

`social-preview.png` sets its text in the system's sans-serif font through
Cairo, so regenerating it on another machine may change the typeface. The
other assets contain no text.
